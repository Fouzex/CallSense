# Whisper Evaluation Results

This folder contains the evaluation results of three OpenAI Whisper models on Arabic speech datasets.

## Files

| File | Description |
|------|-------------|
| whisper_tiny.csv | Whisper Tiny transcription results |
| whisper_base.csv | Whisper Base transcription results |
| whisper_small.csv | Whisper Small transcription results |
| wer_comparison.csv | WER comparison across models and datasets |
| error_examples.csv | Examples of recordings with high transcription error rates |
| ready_samples.csv | Prepared dataset information |
| all_samples.csv | Combined sample information from the data sources |

## Summary

Whisper Small achieved the lowest overall WER at 58.77%, followed by Base at 74.67% and Tiny at 86.03%.

A lower WER indicates fewer word-level transcription errors. These results apply to the evaluated sample and may not represent performance on all Arabic speech.

Note: Audio files are not included in this folder.
